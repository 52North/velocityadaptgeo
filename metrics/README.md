# MCP vs. RAG Evaluation

The goal of this evaluation is to stress-test the agentic workflow by supplying a variety of different user prompts to the system and then scoring the results.  

## Generating Inputs

The prompt inputs for testing will be generated by paraphrasing a seed prompt. Following linguistic research, they will be generated according to six main categories: Morphological, lexical, syntactical, lexical-syntax, discourse-based, and other. An LLM using chain-of-thought reasoning will create paraphrases of the seed prompt based off a dataset of paraphrase examples (Kovatchev et al. 2019; Wahle et al. 2023).

The goal of the generated prompts is to create sentences that are semantically different yet carry the same intention. To accomplish this, the semantic difference must be maximized while the pragmatic difference must be minimized. One way to measure these differences is through cosine similarity. An embedding model can effectively measure the cosine similarity between two sentences, reflecting how different the sentences are semantically (Reimers & Gurevych, 2019). Incorporating an instruction-tuned model can then reorient the vector space along a specified instruction. Two sentences can then compared to their alignment with that instruction (Su et al. 2023).

An iterative loop will generate these prompts, review their semantic and pragmatic difference, filter according to a threshold, then repeat until a minimum number of prompts have been generated. Semantic similarity will be measured not only against the seed prompt but against other prompts within the same category (and potentially other categories if not too computationally expensive). This will ensure that there are a variety of distinct within each category.
